# 소울크레인 SNS 성과 대시보드

사내 SNS 콘텐츠 성과를 한 화면에서 확인하는 내부용 대시보드입니다.

## 실행 방법

```bash
npm install     # 최초 1회
npm run dev     # http://localhost:5173
```

Node.js 18 이상이 필요합니다.

## 배포 & 공유 (Supabase + Vercel)

링크를 보내면 누구나 접속하고 같은 데이터를 보는 홈페이지를 만들려면
**`배포_가이드.md`** 를 순서대로 따라 하세요 (약 15분, 코딩 불필요).

요약:
1. Supabase 프로젝트 생성 → `supabase_schema.sql` 실행
2. 접속 URL·anon 키 복사
3. Vercel에 배포 + 환경 변수 2개 등록
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`

```bash
npm run build   # 로컬 빌드 확인용 (dist/ 생성)
```

### 저장 방식 자동 전환
- 환경 변수가 **있으면** → Supabase 공유 DB (모두 같은 데이터)
- 환경 변수가 **없으면** → 브라우저 localStorage (지금까지처럼)

코드 수정 없이 환경 변수만으로 전환됩니다. 사이드바 하단에 현재 저장 모드가 표시됩니다.

### 기존 로컬 데이터 이전
브라우저에 입력해 둔 데이터는 Supabase 연결 후 **첫 접속 시 자동으로 1회 업로드**됩니다.
(원본 로컬 데이터는 삭제하지 않습니다.)

## 관리 대상 플랫폼

유튜브 · 인스타그램 · 틱톡 · 페이스북 · **더우인(抖音)**

더우인은 기능이 모두 활성화되어 있고 실제 데이터만 아직 없는 상태입니다.
화면에는 「데이터 입력 대기 중」으로 표시되며, [주간 데이터 입력]에서 콘텐츠를 등록하면
대시보드·플랫폼 분석·주간 비교·AI 분석에 자동으로 포함됩니다. (가상 데이터 없음)

## 전체 통합 성과의 범위

```
전체 SNS 통합 성과
 = LF. 공식 본편(메인)
 + 유튜브 + 인스타그램 + 틱톡 + 페이스북 + 더우인
```

메인 콘텐츠는 **통합 합계에는 포함**되지만, 콘텐츠 순위(TOP 10)와 숏폼/롱폼 비교에서는
규모가 달라 결과를 왜곡하므로 **제외**됩니다. 전용 상세 화면에서 따로 관리합니다.

## 성과 등급 기준 (AI 분석)

같은 플랫폼의 **중앙값** 조회수를 기준선으로, 1.5배↑ 🟢 / 0.5배↑ 🟡 / 그 미만 🔴.
평균이 아닌 중앙값을 쓰는 이유는 `src/lib/grading.ts` 상단 주석에 적어두었습니다.

## 데이터 흐름

```
주간 데이터 입력 → store(DataContext) → repository(저장)
                        ↓
    대시보드 · 플랫폼 분석 · 주간 비교 · AI 분석 자동 갱신
```

한 번만 입력하면 나머지 화면은 계산해서 보여줍니다. (엑셀의 중복 입력 제거)

## 저장 계층 구조

```
화면 (pages) → store/DataContext → lib/repository (자동 선택)
                                      ├─ SupabaseRepository (환경변수 있을 때)
                                      └─ LocalRepository    (없을 때)
```

- `lib/supabase.ts` — 접속 클라이언트 (환경변수로 주입)
- `lib/supabaseRepository.ts` — Supabase 읽기/쓰기 (DB↔앱 타입 변환 포함)
- `lib/migrate.ts` — 로컬→Supabase 1회 이전

## 향후 연결 지점

- **AI API**: `src/lib/analysis.ts` 의 `generateInsights` 내부 교체
- **로그인/권한**: `src/App.tsx` 의 `isAdmin` + Supabase Auth 연동
- **YouTube 자동 수집**: `weekly_metrics.source` 필드가 이미 있음 ('manual'|'api')
